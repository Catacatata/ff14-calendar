✨ 项目特点

官方API自动同步 玩家历史数据 自动每日更新 iCalendar标准

本项目通过自动程序获取盛趣官方活动数据， 结合历史整理数据生成 FF14 国服活动日历。 无需依赖个人玩家长期维护，降低因维护者退坑导致的数据中断。

🔄 数据来源

  • 盛趣 FF14 官方活动 API
  • 玩家整理历史活动记录
  • 人工补充特殊活动

📱 支持客户端

  • Apple 日历
  • Google Calendar
  • Outlook
  • 手机系统日历

⏰ 自动更新

每日北京时间 09:00 自动运行更新任务。
